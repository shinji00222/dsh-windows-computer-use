# 0.1.0-preview.3

版本分类：功能预览版。适用于 Windows x64、DSH Desktop 0.2.0-rc.2，以及支持图片输入的模型。

新增看图批量操作：一张截图规划最多 8 个动作，一次执行后返回最终截图和逐步结果，减少模型往返。截图像素坐标会自动换算窗口位置与缩放。原有单步工具和配置继续兼容。

跳转、提交、菜单等步骤设置检查点；滚动和 Enter 自动停组。窗口、焦点、标题或可读取控件变化、失败、取消和 Esc 会阻止剩余操作。返回已完成数量，禁止整组重放。控件检查无法识别所有画布变化，未知页面仍需主动设置检查点。

## 安装与升级

下载下方 `.tgz`，在 DSH Desktop 自带终端执行，替换为文件的实际绝对路径：

```powershell
dsh plugin --profile desktop add "C:\path\to\dsh-windows-computer-use-0.1.0-preview.3.tgz"
```

正常退出并重开 DSH。包内含运行依赖和自包含 C# 引擎，不需要另外安装 .NET SDK。请在 DSH 选择支持图片输入的模型；纯文本模型无法使用看图批量操作，但原有 UIA/OCR 工具仍可使用。

## 验证与边界

验证覆盖真实测试窗口的多步中文输入、截图缩放坐标、失效引用、检查点、弹窗/控件变化、窗口移动、取消和 Esc。实际 DSH 官方桥接验证首尾图片入库并进入 image 消息通道、批量输入回读和纯文本模型拒绝。模型路由元数据使用测试替身，未调用实际模型自主规划，也未替换用户当前 DSH 配置。

引擎在内存中传输截图，DSH 会将图片保存为会话附件。UIA 可能阻塞，超时不自动重放；已经送达应用的输入无法撤销。仍不支持 UAC 安全桌面、后台输入和 WGC，Windows 引擎尚未代码签名。预览版不代表所有应用兼容，GitHub 发布不等于插件市场收录。
