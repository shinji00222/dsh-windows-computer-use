# 0.1.0-preview.4（未发布）

版本分类：功能开发预览版。适用于 Windows x64 / DSH Desktop 0.2.0-rc.2。

新增纯文本控件观察、按编号批量填写和回读，不需要图片模型。每组最多 8 步；点击和按键强制结束当前组，提交后重新确认页面结果。原有配置、单步工具和视觉批量接口兼容。

fill 只支持可赋值的非密码输入框，每项最多 2000 单行字；OCR 只提供文字证据。网页自绘控件、部分无障碍树和前台激活限制可能导致拒绝操作，不会自动盲打。

本版本尚未发布，真实 DS 自主任务与最终包验收待完成。通过验收后再提供 tgz；安装方式仍为 DSH 自带终端的 plugin --profile desktop add 绝对路径，保留旧包并正常重开应用。当前用户继续使用 preview.3。
